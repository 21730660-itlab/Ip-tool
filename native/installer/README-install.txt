IP Monitor for Windows
======================

Start it from the Start menu or the desktop icon "IP Monitor".

The first time: click "Open an existing database file..." and choose your ip-monitor-db.json
(the same file the web version uses), then sign in with your usual username and password.
Every change is saved to that file at once. The app remembers the file for next time.

To remove the program: Settings > Apps > IP Monitor > Uninstall
(or Start menu > IP Monitor > Uninstall IP Monitor). Your database file is never deleted.
